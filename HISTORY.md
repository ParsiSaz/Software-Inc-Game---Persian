# Changelog & Version History

All notable changes to the **Software Inc. Persian Localization Project** are documented here.
The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), adhering to [Semantic Versioning](https://semver.org/).

---

## [v1.2.0] - 2026-10-04

### Changed
- Refactored repository structure to conform with the **ParsiSaz 2026 Localization Standard (L10N-STD-2026)**.
- Organized `.tyd` and `.xml` localization tables into decoupled `loc/fa-IR/` and game drop-in `game_assets/Translations/Persian/`.
- Updated signature `README.md` with installation guides and links to the [ParsiSaz Documentation Portal](https://parsisaz.github.io/parsisaz/).

---

## [v1.1.0] - 2023-09-12

### Added
- Completed translation for office furniture, employee management traits, and hardware manufacturing specs.
- Updated compatibility for Software Inc. Beta builds.

---

## [v1.0.0] - 2022-07-04

### Initial Release
- Initial Persian translation package (UI, software products, and tutorials).
